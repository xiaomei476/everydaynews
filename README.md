# 每日看新闻 · 焊点

一个面向电子信息学习者的中文生产性新闻阅读器：关注会改变研发、制造、供应链、标准和成本的变量，并展示从事实到产业判断的推导过程。

在线访问：

- [主站：焊点 · 每日生产情报](https://solder-daily-radar.true-fairy-7392.chatgpt.site/)
- [静态备用入口（仓库启用 GitHub Pages 后生效）](https://xiaomei476.github.io/everydaynews/)

## 能看什么

- AI、芯片设计与 EDA、晶圆制造、封装、器件、嵌入式、通信、机器人、汽车、能源、标准规则、宏观供应链等行业动态。
- 左侧只显示近 72 小时的标题，右侧显示原始信息摘要与 AI 分析，便于先快速扫读再深入阅读。
- 每条分析固定为“事件核心、产业逻辑拆解、需补充的背景知识、可进一步关注的方向”，并按 C 与 STM32 裸机阶段解释术语。
- 术语可点击查看解释；“我没看懂”会展开预生成的基础讲解，不需要登录或前端 API 密钥。
- 验证追踪直接放在对应新闻末尾，记录验证方法、支持与反驳信号、新证据和下次检查日期。
- 支持本机收藏与标记已读，不需要登录。

## 本地运行

### 环境

- Node.js `>= 22.13.0`
- pnpm（推荐）

### 安装与启动

```bash
pnpm install
pnpm dev
```

启动后访问终端提示的本地地址，通常是 `http://localhost:3000`。

### 检查与构建

```bash
pnpm lint
pnpm build
pnpm start
```

## 内容维护

新闻与验证数据集中在 [app/news-data.ts](app/news-data.ts)。新增内容时，请优先使用政府、统计机构、标准组织、企业正式公告、独立测试与市场数据等一手或可复核来源。

一条新闻应补全原始信息与 `analysis`：

1. `core`：最多三句已确认物理事实；
2. `logic`：从具体证据到影响对象、传导机制和有限结论；
3. `background`：读者可能不了解的术语及其在本条新闻中的作用；
4. `watch`：可观察指标、信号及其解释；
5. 原始来源、日期、关键数字与成熟度边界。

需要长期跟踪的结论应新增关联的验证项，并写明验证方法、支持与反驳信号、最新证据及下次检查时间。不要用重复报道伪造“新进展”。

## 项目结构

```text
app/
  page.tsx        标题流、分析阅读器、术语、收藏与已读交互
  news-data.ts    新闻、行业与验证追踪数据
  globals.css     暖色编辑部风格的界面样式
  layout.tsx      页面元信息与站点壳
.openai/
  hosting.json    已发布站点的部署配置
```

## 部署

项目使用 Vinext 与 OpenAI Sites 构建。完成本地检查后，可将代码推送到主分支，再通过已配置的 Sites 项目保存并发布版本。

仓库同时配置了 GitHub Pages 静态镜像。主分支更新后，GitHub Actions 会运行 `pnpm build:pages`，并把 `out/` 发布到备用入口。静态镜像与主站使用同一份新闻数据；收藏和已读状态仍只保存在访问设备本机。

公开站点无需登录查看；本地收藏与已读记录保存在浏览器本机。
