# 每日看新闻 · 焊点

一个面向电子爱好者的中文生产性新闻看板：关注会改变研发、制造、供应链、标准和成本的变量，而不只是追逐热搜。

在线访问：[焊点 · 每日生产情报](https://solder-daily-radar.true-fairy-7392.chatgpt.site/)

## 能看什么

- AI、芯片设计与 EDA、晶圆制造、封装、器件、嵌入式、通信、机器人、汽车、能源、标准规则、宏观供应链等行业动态。
- 每条新闻提炼“发生了什么、为什么重要、产业影响、电子爱好者视角、下一步验证”。
- 验证追踪：将政策、发布和公司主张拆成可检验命题，记录验证方法、支持与反驳信号、进展和下次检查日期。
- 行业筛选会同步收窄验证追踪；点击新闻的“查看对应验证”会定位到唯一关联的验证项。
- 支持本机收藏与标记已读，不需要登录。

## 本地运行

### 环境

- Node.js `>= 22.13.0`
- pnpm（推荐）

### 安装与启动

```bash
pnpm install
pnpm dev
```

启动后访问终端提示的本地地址，通常是 `http://localhost:3000`。

### 检查与构建

```bash
pnpm lint
pnpm build
pnpm start
```

## 内容维护

新闻与验证数据集中在 [app/news-data.ts](app/news-data.ts)。新增内容时，请优先使用政府、统计机构、标准组织、企业正式公告、独立测试与市场数据等一手或可复核来源。

一条新闻应至少补全：

1. 发生了什么；
2. 为什么会影响生产、研发或供应链；
3. 对电子爱好者可观察或可实践的影响；
4. 下一步需验证的明确事项；
5. 原始来源链接与日期。

需要长期跟踪的结论应新增关联的验证项，并写明验证方法、支持与反驳信号、最新证据及下次检查时间。不要用重复报道伪造“新进展”。

## 项目结构

```text
app/
  page.tsx        页面与筛选、收藏、已读交互
  news-data.ts    新闻、行业与验证追踪数据
  globals.css     暖色编辑部风格的界面样式
  layout.tsx      页面元信息与站点壳
.openai/
  hosting.json    已发布站点的部署配置
```

## 部署

项目使用 Vinext 与 OpenAI Sites 构建。完成本地检查后，可将代码推送到主分支，再通过已配置的 Sites 项目保存并发布版本。

公开站点无需登录查看；本地收藏与已读记录保存在浏览器本机。
